# Diabetes-Prediction-Using-Machine-Learning

📌 Project Overview

This project focuses on building a Machine Learning–based system to predict diabetes in patients using medical and demographic data.
The model helps identify individuals at higher risk of diabetes based on factors such as glucose level, HbA1c, BMI, age, and lifestyle indicators.
The goal of this project is to demonstrate an end-to-end ML workflow, including data preprocessing, model training, evaluation, and interpretation.

🎯 Objective

Predict whether a patient has diabetes or not
Handle imbalanced medical data
Evaluate models using healthcare-relevant metrics
Showcase best practices like pipelines and cross-validation

📂 Dataset Description

The dataset contains patient health records with the following features:
Age
Gender
BMI
Hypertension
Heart Disease
Smoking History
HbA1c Level
Blood Glucose Level
Diabetes (Target Variable)

🛠️ Technologies & Libraries Used

Python 🐍
NumPy
Pandas
Matplotlib & Seaborn
Scikit-learn

🔍 Project Workflow

Data Loading & Exploration
Data Preprocessing
Train-Test Split
Feature Scaling using StandardScaler
Model Building using Logistic Regression
Pipeline creation to prevent data leakage
Model Evaluation using:
F1-score
Precision & Recall
Confusion Matrix
ROC-AUC Curve
Feature Importance Analysis

⚙️ Model Used
Logistic Regression (with Pipeline)
StandardScaler for feature scaling
class_weight='balanced' to handle class imbalance
Cross-validation to ensure model stability

📊 Model Evaluation Metrics

Classification Report
Confusion Matrix
F1 Score
ROC-AUC Curve

📈 Key Insights

Blood glucose level and HbA1c are the most influential features
Feature scaling significantly improves model performance
ROC-AUC shows strong class separation ability
